Methodology

Data Selection & Processing

  • Extracted bicycle-specific accident data from the BAAC dataset (2005-2023)
  • Focused analysis on urban areas with significant cycling infrastructure development
  • Merged multiple data tables (characteristics, locations, vehicles, and casualties) to create comprehensive accident profiles
  • Filtered data to isolate bicycle-related incidents
  • Removed incomplete or invalid entries to ensure data quality

Visualization Techniques

  • Use some D3.js with some vanilla Html,CSS and Javascript
  • Go from a general approch to a more detailled visualization
  • Interactive sunburst charts for yearly and seasonal trends

Data Cleaning Challenges

  • Handle different format and change in data organisation accross the year
  • Handling the multi-table structure of the BAAC dataset
  • Filtering bicycle-specific accidents from the general traffic data
  • Memory limitations when processing large datasets
